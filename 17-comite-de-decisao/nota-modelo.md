# Nota de decisão: folha para preencher

Uma nota por decisão. Escreva na ordem. Cada número vai com o comando que produz ele.

| Parte | O que escrever | Sua nota |
|---|---|---|
| 1. Decisão | Continuar, parar ou reformular, em uma ou duas frases, na primeira linha | |
| 2. Pergunta, dados e regra | O que o teste perguntou, de quem os dados falam, o mínimo ou o empate e a regra, com quem combinou e quando | |
| 3. Números | O efeito e o intervalo contra o mínimo, e as métricas de proteção, com o comando ao lado | |
| 4. Custo e restrições | O que custa cada saída, o teto de exposição se houver, e o que limita a decisão (calendário, operação, validade dos dados) | |
| 5. O que pode estar errado | O que os dados não cobrem e para quem o resultado não vale | |
| 6. Próximo passo | O que acontece, quem faz (uma pessoa, com nome) e até quando | |
| 7. O que muda a decisão | O resultado ou o fato que faria o comitê voltar ao assunto, e o que acontece se nada mudar | |

# Proposta de piloto: folha para preencher

Preencha cada linha com o número e a conta que levou a ele. Use o `piloto.py` e o `briefing.md` dessa pasta. A proposta vai para o comitê antes de qualquer contrato: nada aqui aprova crédito.

| Linha | O que escrever | Sua proposta |
|---|---|---|
| 1. Pergunta | O que muda na regra, para quem, e que resposta o comitê vai receber | |
| 2. Quem entra | Os critérios checados antes do sorteio e o que fica de fora | |
| 3. Sorteio | A unidade (cliente ou proposta), a parte que vai para a regra nova e o que recebe quem fica na regra de hoje | |
| 4. Teto | Perda máxima, pior caso, LGD e valor; quantos contratos e quantos reais cabem | |
| 5. Calendário | Início, fim da contratação, contratos esperados e se cabem no teto | |
| 6. O que mede | A régua do mau e a janela em meses; o que é métrica principal e o que é métrica de proteção | |
| 7. Regra de decisão | O empate, o intervalo usado e as três leituras possíveis, com a chance de cada uma em pelo menos três PDs reais | |
| 8. Regras de parada | O que faz o piloto parar de aprovar antes do fim, com número e com quem decide | |
| 9. Data da resposta | O dia em que a última safra fecha e o comitê que recebe a resposta | |
| 10. O que o piloto não responde | O que continua sem resposta mesmo com o piloto pronto | |

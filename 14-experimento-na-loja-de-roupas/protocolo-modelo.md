# Protocolo do teste

Escrito em: (data, antes do início)
Lido e aceito por: (quem decide e quem opera, com a data)

| Linha | O que escrever | O protocolo |
|---|---|---|
| 1. Pergunta e decisão | A mudança, o que se decide com o resultado e quem decide | |
| 2. Unidade do sorteio | O que o sorteio divide e por quê. Quantas unidades existem | |
| 3. Pares e sorteio | Como os pares são formados, com que dados, e o nome do teste no hash | |
| 4. Operação | O que muda na unidade do B, quem faz, quando começa, o que fica igual nas duas | |
| 5. Exposição | Como saber, todo dia, que o B fez a mudança e que o A não fez | |
| 6. Retorno | A janela de devolução, o atraso do sistema, o "antes" fechado e a data da leitura | |
| 7. Métrica que decide | Numerador, denominador e janela. A conta do efeito | |
| 8. Mínimo que paga | O custo, a margem e a conta | |
| 9. O que o desenho enxerga | O efeito mínimo detectável no histórico e a chance de lançar | |
| 10. Regra de decisão | Lança, não lança ou reformula, escrito antes | |
| 11. Métricas de proteção | Cada uma com limite, quando é lida, a chance de alarme falso, o que acontece e quem decide | |
| 12. Se algo sair do plano | Unidade que sai, contaminação, campanha nova: o que o protocolo manda fazer | |
| 13. O que o teste não responde | Para quem e por quanto tempo o resultado vale | |
